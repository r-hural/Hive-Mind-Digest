# Security policy

## Supported versions

Only the latest release receives security fixes. Please update before you report.

## Reporting a vulnerability

Report it privately through GitHub's private vulnerability reporting:
https://github.com/r-hural/Hive-Mind-Digest/security/advisories/new

Please do not open a public issue, pull request or discussion about it. Include what you found,
the version, and the steps to reproduce it. You will get an answer within 14 days; a fix ships
in the next release, and the release notes credit you unless you ask otherwise.
