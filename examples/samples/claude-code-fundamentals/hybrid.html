5. How we Claude Code

6. Live coding session with Boris Cherny and Jarred Sumner

This live developer session features Boris Cherny (head of Claude Code at Anthropic) and Jarred Sumner (creator of Bun) showing how Bun's team uses Claude Code agents to close the loop on GitHub issues. They are cautious about letting the bot implement every feature request, citing engineering taste, and say Robbun is not yet trusted to merge Bun PRs automatically. The session is demonstrative rather than rigorous: the figures are observations from one project, several claims are openly provisional, and Bun's CLI nature is presented as making verification easier than for browser-based products.
