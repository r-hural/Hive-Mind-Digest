### 5. How we Claude Code

### 6. Live coding session with Boris Cherny and Jarred Sumner

Claude · 2026-05-06 · 32:00 · [watch](https://www.youtube.com/watch?v=DlTCu_pNDHE)

This live developer session features Boris Cherny (head of Claude Code at Anthropic) and Jarred Sumner (creator of Bun) showing how Bun's team uses Claude Code agents to close the loop on GitHub issues. Every new issue in Bun's repository triggers Robbun, a Claude bot that tries to reproduce the problem and submits a PR with tests that must fail on the old version and pass on the fix. The speakers report that Robbun now out-commits Boris on main over the last three months, and that combining CodeRabbit for stylistic checks with Claude's code review for subtle edge cases yields useful reviews, with Claude reportedly wrong about 10% of the time. Key enablers are a detailed CLAUDE.md with build, test and layout instructions, CI-reading agents, and hill-climbing on a metric such as the image-processing benchmark against sharp. The speakers argue the bottleneck has moved through writing code, then running tests, and is now deeper verification and deciding whether a change is correct enough to merge. They describe auto mode as a practical way to let agents run for hours without permission prompts, and no-flicker mode as a rewritten renderer that keeps memory and CPU constant. They are cautious about letting the bot implement every feature request, citing engineering taste, and say Robbun is not yet trusted to merge Bun PRs automatically. The session is demonstrative rather than rigorous: the figures are observations from one project, several claims are openly provisional, and Bun's CLI nature is presented as making verification easier than for browser-based products. The speakers suggest the same pattern could extend to customer support tickets in closed-source companies, though this is speculative.
