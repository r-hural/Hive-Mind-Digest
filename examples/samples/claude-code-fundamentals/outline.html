1. What Claude Code is: an agentic terminal-based coding assistant

1.1 Definition: a fully agentic coding assistant

  • Claude Code is a fully agentic AI coding assistant meant for building features, writing entire functions or files, and fixing whole bugs, rather than completing a few lines of code at a time. [Mastering Claude Code in 30 minutes]
  • Anthropic describes Claude Code as a very pure agent: some instructions and powerful tools, with the model run in a loop until it decides it is done. The tools are those that someone skilled at a terminal would use to create and edit. [Claude Code best practices | Code w/…]
  • The harness is everything around the model: the system prompt, context management, tools, the ability to plug in MCP servers, settings and permissions. The model sees all of this context and output, and it makes a large difference in performance. [The future of agentic coding with…]
  • Coding agents have moved from a gimmick or prototype to part of the everyday inner development loop, so developers now use an agent rather than directly manipulating text in an IDE. [The future of agentic coding with…]

1.2 Works with any IDE or terminal

  • Claude Code works with every IDE and terminal, including VS Code, Xcode, JetBrains IDEs and Vim. It runs locally, over remote SSH and inside tmux, so users do not have to change their existing workflow. [Mastering Claude Code in 30 minutes]

1.3 Code stays local: no indexing

  • Claude Code does not index the codebase or upload it to a remote database. The code stays local, is not used to train generative models, and there is no setup wait before use. [Mastering Claude Code in 30 minutes]
  • Instead of retrieval over an index or embeddings, Claude explores the codebase through agentic search, using tools such as glob, grep and find. It can run further searches based on the results, much as a new team member would explore a codebase. [Claude Code best practices | Code w/…, Mastering Claude Code in 30 minutes]

1.4 Tools, permissions and context

  • By default Claude Code lets read actions such as searching and reading proceed, but asks permission before writing, running bash commands, or doing things that could change the machine. [Claude Code best practices | Code w/…]
  • Bash safety relies on read-only command classification, static analysis of which commands can be safely combined, and a tiered allow-list and block-list permission system, because approving every command manually is impractical. [Mastering Claude Code in 30 minutes]
  • Claude Code has no built-in memory. A CLAUDE.md file in the working directory is placed into the prompt at startup and is the main way state is shared across sessions and teammates. [Claude Code best practices | Code w/…, Mastering Claude Code in 30 minutes]
  • Extension points include CLAUDE.md, settings, a permission system, hooks, MCP servers, slash commands and subagents. Slash commands are reusable markdown workflow files, and subagents are like slash commands that run in a forked context window. [The future of agentic coding with…]

2. Architecture and the harness: agentic search, tools and the model loop

2.1 Tools in a loop: the core agent design

Claude can answer git-history questions, and a 'commit push' prompt produces a commit in the repo's existing format, a pushed branch, and a GitHub pull request.
